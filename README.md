# 小小识字乐园

陪孩子一起学常用三千字的网页程序。纯静态页面，不需要登录，学习进度保存在浏览器本地。

## 运行

双击 `start.bat`（需要本机已安装 PHP），浏览器（推荐 Edge）打开 http://localhost:8080 。
也可以把本目录放在 Apache 的 htdoc 下访问。注意：不能直接双击 `index.html`（浏览器会拦截数据加载）。

## 功能

- 常用三千字：《通用规范汉字表》一级字表 + 字频，由易到难，分 6 个阶段、498 组。
  - 阶段 1「启蒙认字」：数字、方位、家人、身体、大自然、颜色、动物等主题，意义相关的字放一起学。
  - 阶段 2「字族与结构」：会意字、声旁家族（青清请情晴…）、量词、反义词。
  - 阶段 3~6：按字频分层，同偏旁的字分在一组。
- 鼠标放在字上：字放大并播放笔顺动画；详情页有笔顺分解图、“我来写”描红。
- 每个字：拼音、部首、笔画、组词（含拼音和解释）、例句（启蒙阶段）、语音朗读。
- 学习流程：首页 → 识字地图 → 分组概览 → 逐字学习 → 小测验 → 复习（间隔重复）。
- 进度：首页进度环、今日目标、连续天数、阶段进度、14 天曲线、成就徽章；支持多个小朋友档案、导出/导入备份。

## 更新数据

```
pip install pypinyin jieba
npm install --prefix tools
python tools\build_data.py
```

- `tools/curated_groups.py`：启蒙阶段分组。
- `tools/curated_details*.txt`：启蒙阶段每个字的释义/组词/例句（格式：`字|释义|词 词 词|例句`）。
- `tools/word_notes.txt`：人工审核的词语解释（格式：`词|解释`），优先于自动词典释义。

## 可选：预生成高质量语音

```
pip install edge-tts
python tools\gen_audio.py
```

## 说明

阶段 3 之后的词语解释来自新华词典数据的自动整理，个别条目可能不够贴近儿童，可在 `tools/word_notes.txt` 中补充覆盖后重新运行 `build_data.py`。
